What BudgetMonitor Does

BudgetMonitor is a self-hosted personal finance application that I built and operate for managing my own household finances. It securely connects to my own financial accounts, consolidates the transaction and holdings data into a private database running on my personal computer, and produces reporting that is not available from any single institution's own app.

Specifically, it:

  • Retrieves transactions and balances from my own checking, savings, and credit card accounts
  • Retrieves investment holdings and investment transactions from my own brokerage accounts
  • Categorizes spending and tracks it against a monthly budget tied to my pay cycle
  • Reports portfolio composition, cost basis, and unrealized gain/loss across brokerages
  • Calculates a consolidated net-worth figure spanning cash, investments, and debt

Scope of Use

This is a personal-use application, not a commercial product or service. It has a single user — me, the developer and account owner. It is not distributed, not offered to the public, has no customers or end users, and does not process data belonging to anyone other than myself. Every account it connects to is an account I personally own.

How Account Data Is Accessed

BudgetMonitor uses Plaid to connect to financial institutions. Authentication is handled entirely by Plaid Link and the institution's own OAuth flow.

  • Read-only. The application only retrieves account, transaction, and holdings data. It cannot move money, initiate payments, or modify anything at the institution.
  • No credentials are ever seen by the application. Banking usernames and passwords are entered directly with the institution through Plaid's OAuth flow. BudgetMonitor never receives, handles, or stores them.
  • Access tokens are encrypted at rest. Plaid access tokens are encrypted locally and are never committed to source control or transmitted anywhere.
  • All transport is HTTPS. API communication with Plaid occurs exclusively over TLS.

Where Data Is Stored

All retrieved financial data is stored in a PostgreSQL database on my own password-protected personal computer. There is no hosted backend, no cloud database, and no server that any other person can reach.

Financial data is never sold, shared, transmitted to third parties, used for advertising, or used to train any model. There are no analytics or tracking services in the application. Data is retained only as long as it is useful to me and can be deleted by me at any time.
